## Requirements 

- Java 21 
- No gradle installation; it comes with wrapper already

## Build
from SdpLearningMaterial directory: 
1. ./gradlew clean build

## Run 
Choose formats: 

### Markdown 
./gradlew run --args="markdown" 

### JSON 
./gradlew run --args="json" 

### YAML 
./gradlew --args="yaml" 

### Tests
./gradlew test
